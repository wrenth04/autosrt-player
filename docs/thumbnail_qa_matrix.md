# Thumbnail 九宮格 QA 測試矩陣

## 操作情境
- 暫停中開啟九宮格（預期：可載入縮圖，點擊可 seek）。
- 播放中開啟九宮格（預期：不阻塞主播放器，縮圖任務可取消重排）。
- 拖曳中開啟九宮格（預期：新請求取消舊請求，只保留最新任務）。

## 媒體來源
- 本地檔案（file:// 或 content://）。
- 串流來源（http/https，含 header 的來源）。

## 編碼與 GOP
- H.264（短 GOP / 長 GOP）。
- H.265（短 GOP / 長 GOP）。

## 壓力情境
- 長影片（>90 分鐘）：驗證抽幀/採樣點降低策略。
- 高位元率（例如 4K 高碼率來源）：驗證縮圖最大解析度限制（320p/480p）。
- 低階裝置：驗證單點解碼、任務取消、fallback 快取縮圖。

## fallback 驗證
- 人為讓 Thumbnail 初始化失敗（錯誤 URL / header）：
  - 若存在最近成功快取，應顯示快取縮圖與提示訊息。
  - 若沒有快取，應顯示錯誤訊息。
